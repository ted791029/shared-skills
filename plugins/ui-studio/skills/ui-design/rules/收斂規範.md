# 收斂規範

## Rule 1 -- 只降低視覺強度

**強度：MUST**

讓設計安靜下來時，只能調整顏色飽和度、字重、裝飾、特效、動態與間距等視覺強度。內容、文案、功能、資訊架構與品牌辨識維持原樣，除非使用者明確要求一併修改。

### Good Example

這個範例只降低按鈕的飽和度與陰影，按鈕文字與功能不變。

```css
.btn-primary {
  background: oklch(55% 0.12 255); /* 原為 0.22 */
  box-shadow: 0 1px 2px rgb(0 0 0 / 0.08);
}
```

### Bad Example

這個範例在收斂時刪掉了次要按鈕並改寫標題文案，使用者只覺得畫面太吵，卻失去了原有的功能與訊息。

```html
<h1>簡單管理</h1>
<!-- 原本的「下載報表」按鈕被移除 -->
<button class="btn-primary">開始</button>
```

## Rule 2 -- 用途與受眾不明時白話詢問

**強度：MUST**

程式碼與 PRODUCT.md 看不出這個畫面的用途（行銷頁、工作工具、閱讀頁）或主要使用者是誰時，必須先以白話詢問，不得自行猜測。

### Good Example

這個範例用白話詢問畫面用途與使用者，提供具體選項。

```text
想先確認這個畫面主要是給誰用的：
1. 第一次來的潛在客戶，看完決定要不要註冊
2. 每天都在用的內部同事，用來處理工作
3. 其他（請簡單描述）
```

### Bad Example

這個範例沒有確認就假設是行銷頁並保留大量動畫，若實際上是每天使用的工具，收斂結果仍然讓人分心。

```text
我判斷這是行銷頁面，所以保留了主要動畫，只減少了部分顏色。
```

## Rule 3 -- 降低飽和度與顏色數量

**強度：SHOULD**

把過度飽和的顏色降到原彩度的 70%～85%，減少使用的顏色種類，讓中性色承擔大部分面積，強調色約占畫面 10%。高對比只留給最重要的地方。

### Good Example

這個範例把主色彩度從 0.24 降到約 0.18（約 75%），背景改由中性色承擔。

```css
:root {
  --color-accent: oklch(60% 0.18 30);   /* 原為 0.24 */
  --color-canvas: oklch(98% 0.004 30);
}
```

### Bad Example

這個範例保留全飽和的主色，還鋪滿整個背景，強調色占據大半畫面，看久了刺眼疲勞。

```css
body { background: oklch(60% 0.24 30); }
```

## Rule 4 -- 彩色底上不用灰色文字

**強度：MUST**

有色背景上的文字不得使用灰色，改用該背景色相的較深或較淺色；也不得用透明度調淡文字，因為對比會隨背後內容變動。

### Good Example

這個範例在淺綠背景上以深綠色作為次要文字。

```css
.notice { background: oklch(95% 0.03 150); }
.notice small { color: oklch(40% 0.06 150); }
```

### Bad Example

這個範例在淺綠背景上使用半透明灰字，文字顯得髒污且對比不穩定。

```css
.notice small { color: rgb(128 128 128 / 0.6); }
```

## Rule 5 -- 字重降階但保留錨點

**強度：SHOULD**

把過重的字重降階（900 → 600、700 → 500），縮小過大的尺寸跳躍，改以字重、尺寸與留白表達層級，而不是靠顏色與粗體。仍要保留少數最重要的元素作為視覺錨點。

### Good Example

這個範例把標題字重從 900 降到 600，但保留主標題的尺寸作為錨點。

```css
h1 { font-weight: 600; font-size: var(--text-display); }
h2 { font-weight: 500; }
```

### Bad Example

這個範例把所有標題與內文都改成同樣大小的 400 字重，層級完全消失，讀者找不到重點。

```css
h1, h2, h3, p { font-size: 1rem; font-weight: 400; }
```

## Rule 6 -- 移除沒有功能的裝飾

**強度：SHOULD**

移除不承擔層級或功能的漸層、陰影、紋理、光暈、模糊與多層陰影；邊框改細、降低不透明度或移除；收斂過大的圓角差異。

### Good Example

這個範例把多層陰影與光暈換成一層輕微陰影，邊框改細。

```css
.card {
  box-shadow: 0 1px 3px rgb(0 0 0 / 0.06);
  border: 1px solid var(--color-border);
}
```

### Bad Example

這個範例保留光暈、漸層背景與三層陰影，只是稍微調淡，裝飾仍然搶走內容的注意力。

```css
.card {
  background: linear-gradient(135deg, #fdf2f8, #eef2ff);
  box-shadow: 0 0 24px #f0abfc, 0 8px 16px #0003, 0 24px 48px #0002;
}
```

## Rule 7 -- 收斂動態幅度

**強度：SHOULD**

保留有功能的動態、移除純裝飾的動畫。保留的動態位移縮短到 10～20px（不用 40px 以上），緩動曲線使用動態規範 Rule 4 的減速曲線，時長落在該表的範圍內。

### Good Example

這個範例把進場位移縮短為 12px，並使用減速曲線與一般狀態變化的時長。

```css
.toast-enter {
  transform: translateY(12px);
  transition: transform 200ms cubic-bezier(0.25, 1, 0.5, 1);
}
```

### Bad Example

這個範例保留 60px 的大幅位移與每個區塊都有的進場動畫，畫面捲動時一直有東西飛進來，令人分心。

```css
.section { animation: slide-in 800ms ease 1; transform: translateY(60px); }
```

## Rule 8 -- 禁止彈跳與彈性緩動

**強度：MUST**

收斂後的動態不得使用彈跳（bounce）或彈性（elastic）緩動，也不得使用超出終點再回彈的曲線。

### Good Example

這個範例使用不超出終點的減速曲線。

```css
.menu { transition: opacity 150ms cubic-bezier(0.25, 1, 0.5, 1); }
```

### Bad Example

這個範例的曲線第二個控制點超過 1，選單打開時會衝過頭再彈回，與「安靜」的目標相反。

```css
.menu { transition: transform 400ms cubic-bezier(0.68, -0.55, 0.27, 1.55); }
```

## Rule 9 -- 安靜但不平庸

**強度：MUST**

收斂後仍須保留層級、顏色與產品個性。不得變成「白底灰字、單一字型同一字重、一排相同卡片」的平庸樣貌，也不得移除所有顏色或把所有元素都改得又小又淡。

### Good Example

這個範例降低了強度，但保留品牌強調色在主要動作上，並維持標題的字型個性。

```css
h1 { font-family: var(--font-display); font-weight: 600; }
.btn-primary { background: var(--color-accent); }
p { color: var(--color-text-primary); }
```

### Bad Example

這個範例把顏色全部移除、字型統一成系統字型，畫面雖然安靜，卻和任何範本沒有差別，品牌特色消失。

```css
* { font-family: system-ui; color: #6b7280; background: #fff; }
```

## Rule 10 -- 功能元素保持可辨識

**強度：MUST**

收斂後按鈕、連結、輸入框與焦點狀態必須仍然一眼可辨識為可操作的元素。不得移除按鈕的背景或邊框到看起來像一般文字，也不得移除焦點框。

### Good Example

這個範例把次要按鈕改為細邊框樣式，仍看得出是按鈕，並保留焦點框。

```css
.btn-secondary { border: 1px solid var(--color-border-strong); background: transparent; }
.btn-secondary:focus-visible { outline: 2px solid var(--color-focus); outline-offset: 2px; }
```

### Bad Example

這個範例把按鈕的背景、邊框與焦點框全部拿掉，按鈕和一般文字無法區分，鍵盤使用者也看不到目前位置。

```css
.btn-secondary { border: none; background: none; outline: none; }
```
