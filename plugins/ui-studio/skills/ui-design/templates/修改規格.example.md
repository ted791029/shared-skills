## 動態主張

這次沒有新增或修改動態；按鈕的顏色轉換沿用 `--duration-feedback` 與 `--ease-out`。

## 驗收方式

- 在 390、768、1024、1440 四種寬度開啟 `/login`，欄位間距與按鈕高度和 `design/prototype/login-form.html` 一致。
- 連點登入按鈕只送出一次請求，送出中按鈕顯示「登入中…」且無法點擊。
- 輸入錯誤密碼後，螢幕閱讀器在密碼欄朗讀錯誤訊息。
- 全專案搜尋 `.login-shadow` 沒有結果。
