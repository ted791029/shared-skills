## SOP

### Phase 1 --- 判斷需求

1. READ 依 [素材判斷規範](rules/素材判斷規範.md) 讀取使用者需求或呼叫者指定的參數、DESIGN.md 的素材節、既有素材清單、原型與專案程式碼中已用的圖示套件。
2. THINK 依 [素材判斷規範](rules/素材判斷規範.md) 判斷這次的範圍，找出需要的圖示、插圖與照片，區分必須是真實產品或場所的照片與示意素材，並找出以 emoji 或符號代替圖示、缺圖的位置。
3. ASK 依 [白話提問規範](../ui-design/rules/白話提問規範.md) 在素材方向不明且可以詢問時以白話選項詢問使用者。

### Phase 2 --- 選定來源

1. THINK 依 [素材來源規範](rules/素材來源規範.md) 在範圍包含選定來源或 DESIGN.md 沒有素材節時，選定圖示庫、插圖風格與照片來源。
2. WRITE 依 [素材來源規範](rules/素材來源規範.md) 在使用者直接使用且 DESIGN.md 存在時增修素材節，被呼叫時改為回報選定的來源。

### Phase 3 --- 取得素材

1. WRITE 依 [素材取得規範](rules/素材取得規範.md) 在範圍包含取得素材時，把素材取得到素材位置。
2. WRITE 依 [素材清單.md](templates/素材清單.md) 與 [素材清單.example.md](templates/素材清單.example.md) 記錄每個素材的來源與授權，以及正式畫面中要替換的位置。

### Phase 4 --- 檢查與回報

1. THINK 依 [素材取得規範](rules/素材取得規範.md) 檢查每個素材都有授權紀錄、需署名的已註明、佔位圖與要替換的位置都已列出。
2. WRITE 回報選定的來源、取得的素材、佔位圖、要替換的位置與需要使用者處理的授權問題。
