# 腳本邊界判斷

## Rule 1 -- 只抽確定性的機械動作

**強度：MUST**

只有相同輸入必定得到相同輸出的機械動作（如解析、轉換、計算、格式驗證、批次檔案操作）可以交給腳本。需要理解語意、權衡取捨或與使用者互動的部分必須留給 AI。指定 Step 同時包含兩者時，只抽出機械動作的部分。以下 Example 皆對照此指定 Step：

```markdown
2. THINK 統計每份 RuleFile 的 Rule 數量並判斷是否需要拆分。
```

### Good Example

這個範例只把可機械計算的「統計 Rule 數量」交給腳本，「是否拆分」的判斷仍留給 AI。

```markdown
交給腳本：統計每份 RuleFile 的 Rule 數量 → scripts/count_rules.py
留給 AI：依各 RuleFile 的內容與數量判斷是否需要拆分
```

### Bad Example

這個範例把「是否拆分」也寫成腳本中的固定門檻，判斷被寫死成數字，AI 無法再依 Rule 的實際內容取捨。

```markdown
交給腳本：統計 Rule 數量，超過 6 條即輸出「需要拆分」 → scripts/check_split.py
留給 AI：無
```

## Rule 2 -- 單一指令可完成時不寫腳本

**強度：MUST**

若動作是 AI 以一次工具呼叫或一行現成指令就能穩定完成的事（如讀取檔案、列出目錄），不寫腳本，並在回覆中說明不抽取的理由。

### Good Example

這個範例判斷指定 Step 只是讀取檔案，AI 本身即可穩定完成，因此不寫腳本。

```markdown
指定 Step：1. READ 讀取目標 skill 的 SKILL.md。

判斷：單次讀檔即可完成，沒有可加速或易出錯的機械處理 → 不寫腳本。
```

### Bad Example

這個範例為單純讀檔寫了一支腳本，多出一個需要維護的檔案，AI 還得多花一次呼叫執行它，沒有任何好處。

```markdown
指定 Step：1. READ 讀取目標 skill 的 SKILL.md。

預計撰寫：scripts/read_skill.py
```

## Rule 3 -- 腳本只涵蓋指定步驟

**強度：MUST**

撰寫的腳本只能處理使用者指定 Step 的動作。其他 Step 即使也適合交給腳本，只在回覆中提出建議，由使用者決定。以下 Example 皆對照此 SOP 與指定 Step：

```markdown
### Phase 1 --- 擷取欄位

1. THINK 擷取 PDF 表單的所有欄位名稱與位置。

### Phase 2 --- 填寫表單

1. WRITE 依欄位對照表將資料填入 PDF 表單。

指定 Step：Phase 1 Step 1
```

### Good Example

這個範例只為指定的 Phase 1 Step 1 撰寫腳本，對 Phase 2 只提出建議。

```markdown
預計撰寫：scripts/extract_fields.py（Phase 1 Step 1）

建議（未執行）：Phase 2 Step 1 的填寫表單也是機械動作，可另行抽成腳本。
```

### Bad Example

這個範例順手把未指定的 Phase 2 也寫成腳本，修改超出使用者指定的範圍，未經使用者審視的腳本被加入 skill。

```markdown
預計撰寫：
- scripts/extract_fields.py（Phase 1 Step 1）
- scripts/fill_form.py（Phase 2 Step 1）
```

## Rule 4 -- 既有腳本以沿用取代重寫

**強度：MUST**

撰寫前必須檢查目標 skill 的 `scripts/`。已有腳本能完成指定動作時，不得另寫新腳本，改為直接掛載；既有腳本只缺部分功能時，擴充既有腳本。以下 Example 皆對照此既有腳本：

```text
scripts/extract_fields.py：擷取 PDF 表單欄位名稱，尚未輸出欄位位置
```

### Good Example

這個範例在既有腳本只缺欄位位置時擴充既有腳本，不另寫新腳本。

```markdown
部分涵蓋：scripts/extract_fields.py 缺少欄位位置
處理：在 scripts/extract_fields.py 補上欄位位置輸出，不新增腳本。
```

### Bad Example

這個範例在已有腳本的情況下另寫名稱相近的新腳本，兩支腳本都會解析 PDF 欄位，日後修正其中一支時另一支容易被遺漏。

```markdown
既有：scripts/extract_fields.py

預計撰寫：scripts/extract_field_positions.py
```
