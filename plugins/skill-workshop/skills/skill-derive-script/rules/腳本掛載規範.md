# 腳本掛載規範

## Rule 1 -- 委派腳本必須同時掛載腳本執行規範

**強度：MUST**

將指定 Step 改為委派腳本時，除了腳本本身，必須在同一 Step 以「與」掛載腳本執行規範。以下 Example 皆對照此改寫前的 Step：

```markdown
1. THINK 擷取 PDF 表單的所有欄位名稱與位置。
```

### Good Example

這個範例同時掛載腳本與腳本執行規範，執行的 AI 在跑腳本前就知道要使用 `uv run`。

```markdown
1. DELEGATE 依 [extract_fields.py](scripts/extract_fields.py) 與 [腳本執行規範](rules/script-執行規範.md) 擷取 PDF 表單的所有欄位名稱與位置。
```

### Bad Example

這個範例只掛載腳本，執行的 AI 不知道要使用 `uv run`，可能以 `python` 直接執行，因缺少依賴而失敗。

```markdown
1. DELEGATE 依 [extract_fields.py](scripts/extract_fields.py) 擷取 PDF 表單的所有欄位名稱與位置。
```

## Rule 2 -- 腳本執行規範必須掛載目標 skill 內的副本

**強度：MUST**

掛載腳本執行規範時，路徑必須指向目標 skill 自己 `rules/` 底下的副本 `rules/script-執行規範.md`，不得以 `../` 指向 skill-form-script 或其他 skill 內的檔案。產出的 skill 會被單獨複製到其他專案使用，指向外部的連結會在那裡失效。

### Good Example

這個範例掛載目標 skill 內的副本，skill 被複製到其他專案時執行規範會一起帶過去。

```markdown
1. DELEGATE 依 [extract_fields.py](scripts/extract_fields.py) 與 [腳本執行規範](rules/script-執行規範.md) 擷取 PDF 表單的所有欄位名稱與位置。
```

### Bad Example

這個範例以 `../` 掛載 skill-form-script 內的原版，skill 複製到沒有安裝 skill-form-script 的專案後連結失效，執行的 AI 讀不到執行規範，又會以 `python` 直接執行而失敗。

```markdown
1. DELEGATE 依 [extract_fields.py](scripts/extract_fields.py) 與 [腳本執行規範](../skill-form-script/rules/script-執行規範.md) 擷取 PDF 表單的所有欄位名稱與位置。
```
