# 規則連動調整

## Rule 1 -- 只刪改已由樣板表達的 Rule

**強度：MUST**

逐條檢查指定 Step 已掛載的 RuleFile：要求已完全由樣板結構表達的 Rule 必須刪除；只有部分被表達的 Rule 必須改寫為只保留未被表達的部分；與樣板無關的判斷類 Rule 不得修改。刪除後依 skill-form-rule 重新連續編號。以下 Example 皆對照此骨架與調整前的 RuleFile：

```markdown
## SOP

### Phase {{phase_number}} --- {{phase_name}}

{{step_number}}. {{action_verb}} {{step_behavior}}
```

```markdown
# SOP 格式規範

## Rule 1 -- SOP 必須寫在 `## SOP` 區塊

**強度：MUST**

SOP 的 Phase 與 Step 必須寫在 `## SOP` 區塊內。

## Rule 2 -- Phase 順序必須呈現自然流程

**強度：MUST**

Phase 必須依判斷需求、執行、驗證的自然流程排序。

## Rule 3 -- Phase 標題必須使用固定格式且編號連續

**強度：MUST**

Phase 標題必須寫成 `### Phase N --- 名稱`，且編號從 1 起連續遞增。
```

### Good Example

這個範例刪除已由骨架 `## SOP` 標題完全表達的 Rule 1，把 Rule 3 改寫為只保留骨架未表達的編號連續，判斷類的 Rule 2 不修改，並重新連續編號。

```markdown
# SOP 格式規範

## Rule 1 -- Phase 順序必須呈現自然流程

**強度：MUST**

Phase 必須依判斷需求、執行、驗證的自然流程排序。

## Rule 2 -- Phase 編號必須連續遞增

**強度：MUST**

Phase 編號必須從 1 起連續遞增。
```

### Bad Example

這個範例保留已由骨架完全表達的「SOP 必須寫在 `## SOP` 區塊」Rule，與樣板重複，日後修改樣板時兩處可能分歧。

```markdown
# SOP 格式規範

## Rule 1 -- SOP 必須寫在 `## SOP` 區塊

**強度：MUST**

SOP 的 Phase 與 Step 必須寫在 `## SOP` 區塊內。

## Rule 2 -- Phase 順序必須呈現自然流程

**強度：MUST**

Phase 必須依判斷需求、執行、驗證的自然流程排序。

## Rule 3 -- Phase 編號必須連續遞增

**強度：MUST**

Phase 編號必須從 1 起連續遞增。
```

## Rule 2 -- RuleFile 清空時必須一併移除

**強度：MUST**

RuleFile 的所有 Rule 都被刪除時，必須刪除該 RuleFile，並移除指定 Step 中對它的連結引用，不得留下空檔案或失效連結。以下 Example 皆對照此情境：

```text
rules/sop-格式規範.md 的 Rule 已全部刪除，檔案已移除。
```

### Good Example

這個範例在 RuleFile 清空後刪檔，Step 只掛載樣板。

```markdown
1. WRITE 依 [sop.md](templates/sop.md) 與 [sop.example.md](templates/sop.example.md) 在 `## SOP` 區塊撰寫重點步驟。
```

### Bad Example

這個範例的 RuleFile 已被刪除，Step 仍保留指向它的失效連結，agent 依連結讀取時會找不到檔案。

```markdown
1. WRITE 依 [SOP 格式規範](rules/sop-格式規範.md) 與 [sop.md](templates/sop.md) 與 [sop.example.md](templates/sop.example.md) 在 `## SOP` 區塊撰寫重點步驟。
```

## Rule 3 -- 只調整指定 Step 掛載的 RuleFile

**強度：MUST**

連動調整只限指定 Step 掛載的 RuleFile。其他 Step 掛載的 RuleFile 即使也有與樣板重複的 Rule，只在回覆中提出建議，由使用者決定。以下 Example 皆對照此 SOP 與指定 Step：

```markdown
### Phase 2 --- 撰寫 SOP

1. WRITE 依 [SOP 格式規範](rules/sop-格式規範.md) 在 `## SOP` 區塊撰寫重點步驟。

### Phase 3 --- 精簡 SOP

1. WRITE 依 [SOP 精簡規範](rules/sop-精簡規範.md) 刪除完成條件、範例、模板與多餘說明。

指定 Step：Phase 2 Step 1
```

### Good Example

這個範例只調整指定 Step 掛載的 `sop-格式規範.md`，對 Phase 3 掛載的 RuleFile 只提出建議。

```markdown
已調整：rules/sop-格式規範.md（刪除 Rule 1）

建議（未執行）：rules/sop-精簡規範.md 的 Rule 3 也描述 Phase 標題格式，可考慮刪除。
```

### Bad Example

這個範例順手修改了 Phase 3 掛載的 RuleFile，修改超出使用者指定的範圍，未經使用者審視的規範被刪除。

```markdown
已調整：
- rules/sop-格式規範.md（刪除 Rule 1）
- rules/sop-精簡規範.md（刪除 Rule 3）
```
