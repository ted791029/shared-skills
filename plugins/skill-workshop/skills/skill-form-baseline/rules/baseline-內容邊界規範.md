# 基準內容邊界規範

## Rule 1 -- 基準只放對照資料

**強度：MUST**

基準檔只能包含被 Rule 拿來對照的資料本身（條目、句型、原文、圖）。不得寫入強度、要求、判斷標準、取捨條件、Good Example 或 Bad Example；這些屬於引用它的 RuleFile。

### Good Example

這個範例只有錯誤代碼的資料，沒有任何要求。

```markdown
| code | HTTP 狀態 | 訊息句型 |
|---|---|---|
| ORDER_NOT_FOUND | 404 | 找不到訂單 <訂單編號> |
```

### Bad Example

這個範例在基準中寫入要求，同一項要求同時出現在基準與 RuleFile，日後修改時兩處可能分歧。

```markdown
`code` 必須取自下表，不得自創。

| code | HTTP 狀態 | 訊息句型 |
|---|---|---|
| ORDER_NOT_FOUND | 404 | 找不到訂單 <訂單編號> |
```

## Rule 2 -- 轉錄的原文不得增刪改寫

**強度：MUST**

標示為逐字轉錄的內容必須與來源完全相同，不得摘要、改寫用字、補上來源沒有的條目或刪去條目。轉錄者自己的說明（例如來源有疑義之處）必須與原文分開，並標示為「轉錄註記」。

### Good Example

這個範例的訊息句型與來源逐字相同，轉錄者的疑問另外標為轉錄註記。

```markdown
| PAYMENT_DECLINED | 402 | 信用卡授權失敗，請改用其他付款方式 |

- 轉錄註記：來源文件第 3 節把此代碼的 HTTP 狀態寫成 400，第 5 節寫成 402，此處依第 5 節。
```

### Bad Example

這個範例把訊息句型改寫得更通順，檢查腳本逐字比對時，照來源撰寫的正確訊息會被判為錯誤。

```markdown
| PAYMENT_DECLINED | 402 | 您的信用卡未通過授權，建議換一種付款方式 |
```
