## SOP

### Phase 1 --- 判斷需求

1. READ 讀取使用者需求與目標樣板。
2. THINK 依 [樣板內容邊界規範](rules/template-內容邊界規範.md) 判斷樣板的檔案格式、固定結構、需填位的欄位與屬於產出檔案的內容。
3. ASK 需求不明時詢問使用者。

### Phase 2 --- 撰寫樣板

1. WRITE 需求包含骨架時依 [樣板骨架規範](rules/template-骨架規範.md) 撰寫骨架。
2. WRITE 需求包含範例時依 [樣板範例規範](rules/template-範例規範.md) 撰寫範例。
3. WRITE 回報判定不屬於產出檔案的推理、流程與指示。
