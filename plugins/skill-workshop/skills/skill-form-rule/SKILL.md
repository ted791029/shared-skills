## SOP

### Phase 1 --- 判斷需求

1. READ 讀取使用者需求與目標 RuleFile。
2. THINK 判斷需要規範的項目。
3. ASK 需求不明時詢問使用者。

### Phase 2 --- 撰寫 RuleFile

1. WRITE 依 [rule-file.md](templates/rule-file.md) 與 [rule-file.example.md](templates/rule-file.example.md) 建立 RuleFile 標題與每條 Rule 的欄位結構。
2. WRITE 依 [RuleFile 格式規範](rules/rule-file-格式規範.md) 撰寫每條 Rule 的名稱、描述與 Example。
3. WRITE 依 [Rule 執行強度規範](rules/rule-file-執行強度規範.md) 標示每條 Rule 的強度。
