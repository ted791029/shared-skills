## SOP

### Phase 1 --- 判斷需求

1. READ 讀取使用者需求與目標 skill。
2. THINK 判斷是否需要 SOP。
3. ASK 需求不明時詢問使用者。

### Phase 2 --- 撰寫 SOP

1. WRITE 依 [SOP 格式規範](rules/sop-格式規範.md) 與 [sop.md](templates/sop.md) 與 [sop.example.md](templates/sop.example.md) 在 `## SOP` 區塊以 Phase 與標準動詞撰寫重點步驟。
2. WRITE 依 [SOP 檔案掛載規範](rules/sop-檔案掛載規範.md) 在需要使用檔案的 Step 加入連結。

### Phase 3 --- 精簡 SOP

1. WRITE 依 [SOP 精簡規範](rules/sop-精簡規範.md) 刪除完成條件、範例、模板與多餘說明。
