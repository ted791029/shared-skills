# 條款落點判斷規範

## Rule 1 -- 跨兩份以上產出物才寫成共通條款

**強度：MUST**

同一條約束必須同時作用於本次涉及的兩份以上產出物時，才寫成 `shared/` 的共通條款，並由每份受約束的產出物條款檔引用；只作用於一份產出物的約束一律寫進該產出物的條款檔。不得因為「之後其他產出物可能也用得到」而預先寫成共通條款。

### Good Example

這個範例的命名約束同時作用在契約與資料模型，因此寫成共通條款，兩份條款檔各自引用。

```markdown
約束：API 欄位 camelCase、資料表欄位 snake_case，兩邊名稱可互相換算。
作用於：specs/truth/contracts/、specs/truth/data/
落點：shared/欄位命名風格.md（C-SH-01）；skills/api-plan/contracts.md 與 skills/data-plan/data.md 引用 C-SH-01
```

### Bad Example

這個範例的約束只作用於契約，卻因為預期以後會用到而放進 shared/，共通條款沒有被第二份產出物引用，徒增一層間接查找。

```markdown
約束：成功回應一律包成 data 與 meta。
作用於：specs/truth/contracts/
落點：shared/回應包裝.md（C-SH-02）；skills/api-plan/contracts.md 引用 C-SH-02
```

## Rule 2 -- 條款 ID 依產出物前綴遞增

**強度：MUST**

條款 ID 格式固定為 `C-<前綴>-<兩位數編號>`。前綴依下表；表中沒有的產出物，以產出物英文短名的大寫縮寫作為新前綴，且不得與既有前綴重複。產出物一律以位置表示，表中、目錄與條款檔標題的寫法相同：plan 的產出物寫 plan 資料夾內的路徑，truth 的產出物寫 `specs/truth/` 起的路徑，資料夾以 `/` 結尾；條款檔放在產出 skill 的資料夾，以產出物的檔名（不含副檔名）或資料夾名命名，例如 `specs/truth/data/` 的條款檔是 `skills/data-plan/data.md`、`spec.md` 的是 `skills/specify/spec.md`。編號取同一前綴在憲法中已使用的最大編號加一，已刪除條款的編號不得重複使用。共通條款一律使用 `C-SH`。

| 產出物 | 前綴 |
|---|---|
| spec.md | C-SPEC |
| research.md、specs/truth/techstack.md | C-TR |
| plan.md | C-PLAN |
| ui/ui-contract.md | C-UI |
| ui/prototype/ | C-PROTO |
| specs/truth/contracts/ | C-API |
| specs/truth/data/ | C-DATA |
| specs/truth/storage/storage-contract.md | C-FS |
| tasks.md | C-TASK |

### Good Example

這個範例的 C-API-02 曾被刪除，新條款取最大編號加一，不重用 02。

```markdown
憲法中 C-API 已使用：C-API-01、C-API-02（已刪除）、C-API-03
新條款：C-API-04
```

### Bad Example

這個範例重用已刪除的 C-API-02，先前 plan 的 tasks.md 與 analyze 報告中引用的 C-API-02 會被誤認為新條款。

```markdown
憲法中 C-API 已使用：C-API-01、C-API-02（已刪除）、C-API-03
新條款：C-API-02
```

## Rule 3 -- 共通條款依主題歸檔

**強度：SHOULD**

新的共通條款與既有共通條款檔屬於同一主題時，應寫進該檔，不另開新檔；只有主題不同時才新增 `shared/<主題>.md`，主題名稱使用描述約束對象的中文短語。

### Good Example

這個範例的新條款也是命名約束，因此加進既有的欄位命名風格檔。

```markdown
既有：shared/欄位命名風格.md（C-SH-01）
新條款：列舉值一律大寫底線
落點：shared/欄位命名風格.md 新增 C-SH-02
```

### Bad Example

這個範例為同一主題另開新檔，命名相關的共通條款分散在兩處，引用時容易漏掉其中一份。

```markdown
既有：shared/欄位命名風格.md（C-SH-01）
新條款：列舉值一律大寫底線
落點：shared/列舉命名.md（C-SH-02）
```
