# 澄清標記規範

## Rule 1 -- 只標會改變驗收結果的疑點

**強度：MUST**

只在 spec.md 沒寫清楚、而且不同答案會改變旅程步驟或 Then 結果的地方標出 [NEED CLARIFICATION]；spec.md 已有明確答案、或任何答案都不影響旅程的細節不得標出。

### Good Example

這個範例標出 spec 沒說明「放到另一本相簿上」插在哪裡，不同答案會改變 Then 的相簿順序。

```gherkin
      # [NEED CLARIFICATION] 相簿放到另一本相簿上時，要插在它之前、之後，還是依放開位置決定？暫以「之前」撰寫
      When 把相簿 "2026年10月1日（星期四）" 拖放到相簿 "2026年10月3日（星期六）" 上
```

### Bad Example

這個範例詢問 spec.md 的 FR-006 已明確規定的相簿名稱格式，PM 被迫回答已決定的事，真正影響驗收的疑點反而佔不到題數。

```gherkin
      # [NEED CLARIFICATION] 相簿名稱要不要顯示星期？暫以「顯示」撰寫
      Then 主頁依序顯示下列相簿：
```

## Rule 2 -- 合計至多 10 個並依影響挑選

**強度：MUST**

整個 spec 的所有驗收 feature 合計至多標出 10 個 [NEED CLARIFICATION]，只標實際存在、符合 Rule 1 的疑點；疑點多於 10 個時，保留影響最多旅程或最改變 Demo 結果的 10 個，其餘列入回報的剩餘疑點；疑點少於 10 個時照實際數量標出，沒有疑點時不標，不得為了湊數補標 spec.md 已寫明或任何答案都不改變旅程的細節。增量更新時只計本次新增的疑點。

### Good Example

這個範例找到 12 個疑點時保留影響旅程結果的 10 個，2 個只影響文字措辭的列入剩餘疑點；另一份 spec 只找到 2 個疑點時就只標 2 個，不另外補標。

```text
疑點 12 個 → feature 中標出 10 個
剩餘疑點：空狀態說明文字、匯入按鈕名稱

疑點 2 個 → feature 中標出 2 個
```

### Bad Example

這個範例把 12 個疑點全部標進 feature，超過上限，PM 一次面對大量問題，關鍵決策被細節稀釋。

```text
疑點 12 個 → feature 中標出 12 個
```

## Rule 3 -- 同一疑點只標一次

**強度：MUST**

同一個疑點出現在多個旅程時，只在 AC 編號最小的旅程中第一個受影響的位置標出一次，其他旅程照同一個暫定假設撰寫，不重複標出。

### Good Example

這個範例的「刪除前是否需確認」同時影響 AC-08 與 AC-09，只在 AC-08 標出。

```gherkin
    Example: AC-08 在相簿頁刪除 10 月 1 日相簿的 P3
      # [NEED CLARIFICATION] 刪除照片前是否需要使用者再次確認？暫以「不需確認」撰寫
      And 在相簿頁刪除照片 "P3"

    Example: AC-09 刪除 10 月 3 日相簿僅有的 R1、R2
      And 在相簿頁刪除照片 "R1"
```

### Bad Example

這個範例在兩個旅程各標一次同一個疑點，同一題被問兩次、佔掉兩個題數，兩次回答不一致時也不知道以哪一次為準。

```gherkin
    Example: AC-08 在相簿頁刪除 10 月 1 日相簿的 P3
      # [NEED CLARIFICATION] 刪除照片前是否需要使用者再次確認？暫以「不需確認」撰寫
      And 在相簿頁刪除照片 "P3"

    Example: AC-09 刪除 10 月 3 日相簿僅有的 R1、R2
      # [NEED CLARIFICATION] 刪除照片前是否需要再確認一次？暫以「不需確認」撰寫
      And 在相簿頁刪除照片 "R1"
```

## Rule 4 -- 步驟必須依暫定假設寫完

**強度：MUST**

標出疑點的步驟必須依暫定假設寫成完整可讀的步驟與結果，不得留空、寫「待確認」或使用填位符號；暫定假設取與 spec.md 其他內容一致、最常見的解讀。

### Good Example

這個範例照「自動回到主頁」的暫定假設寫完 Then，澄清前 PM 也能完整讀完這段旅程。

```gherkin
      # [NEED CLARIFICATION] 在相簿頁刪光照片、相簿被移除後，畫面要去哪裡？暫以「自動回到主頁」撰寫
      Then 畫面回到主頁
```

### Bad Example

這個範例把結果寫成「待確認」，旅程在這裡斷掉，PM 無法讀完整段 Demo，後續步驟的起點也無從判斷。

```gherkin
      # [NEED CLARIFICATION] 在相簿頁刪光照片、相簿被移除後，畫面要去哪裡？暫以「自動回到主頁」撰寫
      Then 畫面待確認
```
