# 澄清答案改寫規範

## Rule 1 -- 照暫定的回答採用暫定假設

**強度：MUST**

使用者回答「照暫定」或選擇與暫定假設相同的選項時，以暫定假設作為答案：步驟維持原寫法，只刪除該題的 [NEED CLARIFICATION]，並與其他答案一樣寫回 spec.md。

### Good Example

這個範例在使用者回答照暫定後，保留「畫面回到主頁」並刪除標籤，spec.md 也補上這條決定。

```gherkin
      Then 畫面回到主頁
```

### Bad Example

這個範例在照暫定時保留了標籤，feature 看起來仍有未澄清的疑點，spec.md 也沒有記錄這個決定，下游讀 spec.md 時不知道畫面要回到主頁。

```gherkin
      # [NEED CLARIFICATION] 在相簿頁刪光照片、相簿被移除後，畫面要去哪裡？暫以「自動回到主頁」撰寫
      Then 畫面回到主頁
```

## Rule 2 -- 答案影響的旅程必須一併改寫

**強度：MUST**

答案改變了暫定假設時，除了標出該題的步驟，所有依同一暫定假設撰寫的其他旅程步驟與結果也必須一併改寫，讓全部 feature 與答案一致。以下 Example 皆對照此答案：

```text
AC-08 題目：刪除照片前是否需要使用者再次確認？
回答：需要確認
```

### Good Example

這個範例在 AC-08 與同樣有刪除操作的 AC-09 都補上確認步驟。

```gherkin
    Example: AC-08 在相簿頁刪除 10 月 1 日相簿的 P3
      And 在相簿頁刪除照片 "P3"
      And 確認刪除

    Example: AC-09 刪除 10 月 3 日相簿僅有的 R1、R2
      And 在相簿頁刪除照片 "R1"
      And 確認刪除
```

### Bad Example

這個範例只改了 AC-08，AC-09 仍照「不需確認」撰寫，兩個旅程對刪除流程的描述互相矛盾，PM Demo AC-09 時會卡在確認對話框。

```gherkin
    Example: AC-08 在相簿頁刪除 10 月 1 日相簿的 P3
      And 在相簿頁刪除照片 "P3"
      And 確認刪除

    Example: AC-09 刪除 10 月 3 日相簿僅有的 R1、R2
      And 在相簿頁刪除照片 "R1"
```

## Rule 3 -- 改寫只動受答案影響的步驟

**強度：MUST**

把答案改進 feature 時，只修改受答案影響的步驟、表格與其後依賴它的結果，旅程的其他步驟、Example 標題、Rule 名稱與 AC 編號維持原樣。以下 Example 皆對照此答案：

```text
AC-06 題目：相簿放到另一本相簿上時插在哪裡？
回答：插在它之後
```

### Good Example

這個範例只改寫拖放後依賴答案的順序表格，拖放步驟、Example 標題與 AC 編號維持原樣。

```gherkin
      When 把相簿 "2026年10月1日（星期四）" 拖放到相簿 "2026年10月3日（星期六）" 上
      Then 主頁依序顯示下列相簿：
        | 相簿                    | 照片數 |
        | 2026年10月3日（星期六） | 2      |
        | 2026年10月1日（星期四） | 5      |
        | 2026年10月2日（星期五） | 3      |
```

### Bad Example

這個範例藉機把 AC-06 改名並換了變種資料，PM 已經檢視過的旅程被大幅改動，必須重新審視整段，超出這題答案的範圍。

```gherkin
    Example: AC-06 把 10 月 2 日相簿拖到 10 月 1 日相簿上
```
