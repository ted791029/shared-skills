# 規格寫回規範

## Rule 1 -- 問答必須標出 AC 與覆蓋分類

**強度：MUST**

依釐清結果寫回規範把本次的問答寫進本次執行新增的場次時，每題一行的「問」以 `（AC-NN）` 開頭，AC-NN 是這題的題目標籤，也就是澄清標籤所在的 AC；`[<覆蓋分類>]` 取需求覆蓋分類法的分類表中，檢查子項涵蓋這題所問內容的分類名稱。照暫定回答的題目也照樣寫一行。以下 Example 皆對照此既有內容與本次的問答：

```markdown
## 釐清紀錄

### 場次 2026-10-25

- [功能範圍與行為] 問：使用者能否手動把照片移到其他相簿？ → 答：不行，照片永遠位於拍攝日期對應的相簿。

**輸入**：使用者描述：「幫我開發一個應用程式，這個程式可以幫助我將照片整理到不同的相簿中」
```

```text
本次執行：2026-10-25 下午的 spec-by-example
AC-06 題目：相簿放到另一本相簿上時插在哪裡？ → 回答：依放開位置決定，左半部插在它之前，右半部插在它之後
AC-09 題目：刪光照片、相簿被移除後畫面要去哪裡？ → 回答：照暫定，自動回到主頁
```

### Good Example

這個範例在同一天新增「第 2 場」，每行以題目的 AC 開頭並標出覆蓋分類，照暫定的 AC-09 也寫成一行。

```markdown
### 場次 2026-10-25

- [功能範圍與行為] 問：使用者能否手動把照片移到其他相簿？ → 答：不行，照片永遠位於拍攝日期對應的相簿。

### 場次 2026-10-25（第 2 場）

- [互動與使用流程] 問：（AC-06）相簿放到另一本相簿上時插在哪裡？ → 答：依放開位置決定，放開位置在左半部時插在它之前，在右半部時插在它之後。
- [邊界與失敗處理] 問：（AC-09）刪光照片、相簿被移除後畫面要去哪裡？ → 答：自動回到主頁。

**輸入**：使用者描述：「幫我開發一個應用程式，這個程式可以幫助我將照片整理到不同的相簿中」
```

### Bad Example

這個範例沒有寫出 AC 與覆蓋分類，日後看不出這兩題是為哪一段旅程問的、改了哪一個 AC；clarify-over-specs 重新判定覆蓋時也不知道它們補的是哪個分類，同一個缺口可能被再問一次。

```markdown
### 場次 2026-10-25（第 2 場）

- 問：相簿放到另一本相簿上時插在哪裡？ → 答：依放開位置決定，放開位置在左半部時插在它之前，在右半部時插在它之後。
- 問：刪光照片、相簿被移除後畫面要去哪裡？ → 答：自動回到主頁。
```

## Rule 2 -- 只改本次答案對應的需求

**強度：MUST**

寫回 spec.md 時，只能改寫本次答案依釐清結果寫回規範對應到的章節與需求，以及答案確定用語時的全文統一；本次答案沒有涉及的需求、受影響的既有功能與先前的場次一律不改，也不得順手補充細節、改寫措辭或重新排列。以下 Example 皆對照此既有內容與本次的答案：

```markdown
- **FR-010**：相簿頁面**必須**以大小一致的平鋪縮圖呈現照片，預設依拍攝時間由早到晚排序。
- **FR-017**：使用者**必須**能從應用程式刪除照片；刪除僅將照片自應用程式移除，**不得**刪除或修改裝置上的原始檔案。
```

```text
AC-08 題目：刪除照片前是否需要使用者再次確認？ → 回答：需要確認，取消時照片保留
```

### Good Example

這個範例只把確認步驟寫進 FR-017，FR-010 原樣保留。

```markdown
- **FR-010**：相簿頁面**必須**以大小一致的平鋪縮圖呈現照片，預設依拍攝時間由早到晚排序。
- **FR-017**：使用者**必須**能從應用程式刪除照片，刪除前**必須**再次確認，取消時照片保留；刪除僅將照片自應用程式移除，**不得**刪除或修改裝置上的原始檔案。
```

### Bad Example

這個範例順手替 FR-010 補上拍攝時間相同時的排序，PM 沒有被問過這條規則就被寫成需求；FR-010 的內容變了，依據它的 technical-research、system-analysis 與 dsl-refine 都會成為待補跑，為一條沒有人提出的變更重跑。

```markdown
- **FR-010**：相簿頁面**必須**以大小一致的平鋪縮圖呈現照片，預設依拍攝時間由早到晚排序，拍攝時間相同時依檔名排序。
- **FR-017**：使用者**必須**能從應用程式刪除照片，刪除前**必須**再次確認，取消時照片保留；刪除僅將照片自應用程式移除，**不得**刪除或修改裝置上的原始檔案。
```
