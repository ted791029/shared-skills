# UI 契約：照片相簿整理器

**Plan**：`001-photo-album-organizer`

## 共用約定

- 路由：`#/` 為主頁，`#/albums/:albumId` 為相簿頁。
- 訊息語言：繁體中文；錯誤訊息說明「發生什麼事」與「可以怎麼做」。
- 定位屬性：以 `data-testid` 標示可操作元素。
- 回饋時限：點擊、按鍵或拖放後 200 毫秒內出現可見回饋。

## UI-01 主頁相簿列表介面（相簿卡片、空狀態、拖放與鍵盤排序）

**路由**：`#/`
**定位**：`[data-testid="home-album-list"]`

### 操作

| 操作 | 互動 | 需要內層提供 |
|---|---|---|
| 瀏覽相簿列表 | 開啟主頁，以卡片顯示名稱、照片數量與封面縮圖；未自訂順序前依代表日期由新到舊 | 相簿列表（識別、名稱、照片數、封面位址、目前順序） |
| 開啟相簿 | 點選卡片進入相簿頁 | 相簿識別 |
| 開啟匯入 | 點選「匯入照片」開啟匯入對話框 | 無 |
| 拖放排序 | 以指標拖曳卡片至兩本相簿之間的插入點；放到卡片上方只調整順序、不嵌套 | 將指定相簿移到另一本之前，或移到最後 |
| 鍵盤排序 | 聚焦卡片後以 Space／Enter 拿起，方向鍵移動，Space／Enter 放下，Esc 取消 | 與拖放排序相同 |
| 取消排序 | 拖到無效區域或按下 Esc，卡片回到原位 | 無（不送出移動） |

### 狀態

| 狀態 | 呈現 |
|---|---|
| 成功 | 依目前順序顯示全部相簿卡片 |
| 載入 | 卡片位置顯示骨架佔位，版面不跳動 |
| 空狀態 | 說明尚無相簿，並顯示「匯入照片」引導按鈕 |
| 錯誤 | 排序儲存失敗時還原為上一次成功的順序，並提示可再試一次 |

### 文案與無障礙

| 項目 | 文案 |
|---|---|
| 空狀態標題 | 還沒有相簿 |
| 空狀態說明 | 匯入照片後，系統會依拍攝日期自動分成相簿。 |
| 匯入按鈕 | 匯入照片 |
| 封面替代文字 | {相簿日期}，{照片數量} 張照片 |
| 拿起播報 | 已拿起{相簿名稱}，目前位置第 {目前序} 本，共 {總數} 本 |
| 放下播報 | {相簿名稱}已移到第 {新序} 本，共 {總數} 本 |
| 取消播報 | 已取消移動，{相簿名稱}回到原位 |
| 排序失敗 | 無法儲存相簿順序，已還原剛才的排列。請再試一次。 |

## UI-02 匯入對話框介面（選取檔案、進度、略過結果）

**路由**：主頁或相簿頁皆可開啟，不改變 hash
**定位**：`[data-testid="import-dialog"]`

### 操作

| 操作 | 互動 | 需要內層提供 |
|---|---|---|
| 選取照片 | 一次選取多張本機檔案；依副檔名與 MIME 先過濾不支援格式 | 無（前端先過濾） |
| 開始匯入 | 每個檔案各送一次上傳，並行數有上限；過程中可關閉對話框並繼續瀏覽已完成的相簿 | 單張照片匯入（原始檔、可選縮圖、檔案本地時間） |
| 查看進度 | 顯示已完成數／總數的進度條 | 每張的匯入結果（新增、重複、不支援） |
| 查看摘要 | 全部完成後顯示新增數、略過重複數與不支援檔名清單 | 無（前端彙總各次結果） |

### 狀態

| 狀態 | 呈現 |
|---|---|
| 成功 | 顯示新增數量；若有略過或失敗，一併列出 |
| 載入 | 進度條顯示「已完成 N／總數 M」，介面其餘部分可操作 |
| 空狀態 | 尚未選檔時提示選擇 JPEG、PNG 或 HEIC 照片 |
| 錯誤 | 單張失敗不中斷整批；該張列在失敗清單，其餘繼續 |

### 文案與無障礙

| 項目 | 文案 |
|---|---|
| 對話框標題 | 匯入照片 |
| 選檔按鈕 | 選擇照片 |
| 格式提示 | 可選 JPEG、PNG、HEIC，一次可選多張。 |
| 進度列 | 已完成 {完成數}／{總數} |
| 進度列無障礙 | role="progressbar"，aria-valuenow 為完成數、aria-valuemax 為總數 |
| 摘要新增 | 已新增 {數量} 張照片 |
| 摘要重複 | 已略過 {數量} 張重複照片 |
| 摘要不支援標題 | 不支援的檔案 |
| 單張失敗 | {檔名}無法匯入。請確認檔案未損毀後再試一次。 |

## UI-03 相簿平鋪預覽介面（縮圖格線、佔位載入、刪除、日期推估標示）

**路由**：`#/albums/:albumId`
**定位**：`[data-testid="album-photo-grid"]`

### 操作

| 操作 | 互動 | 需要內層提供 |
|---|---|---|
| 瀏覽平鋪 | 以大小一致的縮圖格線呈現，依拍攝時間由早到晚；向下捲動載入後續頁 | 相簿內照片分頁列表（識別、縮圖位址、拍攝時間、是否推估日期、序號） |
| 開啟放大 | 點選縮圖進入燈箱 | 照片識別與在相簿內的前後張識別 |
| 返回主頁 | 點選相簿名稱旁的返回 | 無 |
| 刪除照片 | 在縮圖上確認後刪除；最後一張刪除後返回主頁且該相簿消失 | 刪除指定照片；回傳相簿是否已空 |

### 狀態

| 狀態 | 呈現 |
|---|---|
| 成功 | 格線顯示已載入的縮圖，固定正方形佔位，載入完成不造成版面跳動 |
| 載入 | 每個縮圖位置先顯示骨架佔位 |
| 空狀態 | 不停留在空相簿；刪光後回到主頁空狀態或剩餘相簿列表 |
| 錯誤 | 單張損毀或無法預覽時，該格顯示「無法顯示此照片」，其餘格正常 |

### 文案與無障礙

| 項目 | 文案 |
|---|---|
| 相簿標題 | {YYYY}年{M}月{D}日（星期{X}） |
| 縮圖替代文字 | {相簿日期}，第 {序號} 張 |
| 推估標示 | 日期為推估 |
| 無法預覽 | 無法顯示此照片 |
| HEIC 無法解碼 | 此瀏覽器無法預覽 HEIC 照片 |
| 刪除確認 | 要從相簿移除這張照片嗎？裝置上的原始檔不會被刪除。 |
| 刪除按鈕 | 刪除照片 |
| 刪除失敗 | 無法刪除這張照片，請再試一次。 |

## UI-04 燈箱放大檢視介面（上一張／下一張、返回平鋪、刪除）

**路由**：停留在 `#/albums/:albumId`，以疊層開啟
**定位**：`[data-testid="photo-lightbox"]`

### 操作

| 操作 | 互動 | 需要內層提供 |
|---|---|---|
| 放大檢視 | 顯示該張照片的大圖 | 原圖位址；無法預覽時改提供下載原圖 |
| 上一張／下一張 | 按鈕或方向鍵切換；到盡頭時停用對應方向 | 目前照片的前一張與後一張識別 |
| 返回平鋪 | 關閉疊層或按 Esc，回到格線且焦點回到原縮圖 | 無 |
| 刪除照片 | 確認後刪除；若還有下一張則切過去，否則關閉燈箱 | 與平鋪刪除相同 |

### 狀態

| 狀態 | 呈現 |
|---|---|
| 成功 | 顯示大圖與上一張／下一張控制 |
| 載入 | 大圖區域顯示載入中，控制列仍可關閉 |
| 空狀態 | 不單獨出現；刪到沒有照片時關閉燈箱並離開相簿頁 |
| 錯誤 | 檔案損毀或無法解碼時顯示提示，仍可切換其他張或返回 |

### 文案與無障礙

| 項目 | 文案 |
|---|---|
| 對話名稱 | 照片放大檢視 |
| 上一張 | 上一張 |
| 下一張 | 下一張 |
| 返回平鋪 | 返回相簿 |
| 無法顯示 | 無法顯示此照片。可以下載原始檔，或查看其他照片。 |
| 下載原圖 | 下載原始檔 |
| 刪除確認 | 要從相簿移除這張照片嗎？裝置上的原始檔不會被刪除。 |
| 刪除失敗 | 無法刪除這張照片，請再試一次。 |
