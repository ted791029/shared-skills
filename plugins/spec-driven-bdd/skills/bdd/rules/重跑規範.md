# 重跑規範

## Rule 1 -- 只比對任務描述列出的改動與既有 step

**強度：MUST**

rerun 只比對呼叫者任務描述列出的改動：「句型「…」只改說明」與「參數「…」只改說明」（逐任務必讀引用的 `truth-changes.md` 列寫出改了什麼）；呼叫者沒有附帶時，比對進行中 plan 的 `truth-changes.md` 中範疇所在端點資料夾、改動摘要以「只改說明：」開頭的列。句型找出 dsl.md Step 檔對照登記的 step 與它呼叫的 Driver，參數找出把這個值轉成技術值的自訂參數型別與 Driver 對照，與 dsl.md（參數另含用語表）現在的寫法逐項比對呼叫的入口、帶的欄位、等待、保存的值、斷言與對照的技術值：全部相符，或只有說明文字、引用（如研究編號）與參數名稱不同而 step 比對的步驟文字與行為不變時，判定不用改；這次的改動讓任何一項不符，或範疇內用到這個句型的步驟沒有能比對的 step（undefined、ambiguous）時，判定需要改，依停下回報規範停下並建議改排紅燈。比對只限這次改動的部分：改動之前就存在、與這次改動無關的落差（例如 step 本來就少驗 dsl.md 描述的某項斷言）不算需要改，列在重跑完成說明，交由呼叫者另外處理。任務描述的改動只有「只改了註解」「只刪除了 Example」或「Rule 改名」時，沒有要比對的句型或參數，直接執行範疇。不得只因 Example 執行會通過就判定不用改，也不得自行修改 step 或 Driver 讓兩者一致。

### Good Example

這個範例的起點句型只刪掉說明中重述後端數值的一句，既有 step 與 Driver 從不設定技能次數，其餘動作、等待與保存都與 dsl.md 相符，判定不用改。

```text
任務描述：[重跑] 範疇：`specs/truth/features/frontend/改答案.feature`：句型「系統處於 {前置狀態}」只改說明，確認既有 step 不用改後重新執行
必讀：truth-changes.md › features/frontend/dsl.md ＞ 句型「系統處於 {前置狀態}」（只改說明：刪掉重述的技能剩餘次數）
比對：frontend/tests/e2e/steps/shared/系統狀態.js、frontend/tests/e2e/support/drivers/shared/系統狀態.js 依序 reset、以 API 建房、開各玩家情境、等畫面根元素與聊天列數、保存身份與房間編號，與 dsl.md 相符
判定：不用改 → 執行範疇
```

### Bad Example

這個範例的 dsl.md 在等待加上聊天紀錄的列數，既有 step 只等畫面根元素，卻以 truth-changes 寫了只改說明為由判定不用改；起點建立完成前就開始操作，聊天的 Example 時好時壞，step 也不再符合 dsl.md。

```text
dsl.md 的異動：等待加上「chat-log 的 chat-message 列數等於起點應有的系統訊息數」
比對：shared/系統狀態.js 只等 room-page 出現
判定：不用改（truth-changes 寫只改說明）→ 執行範疇
```

## Rule 2 -- 完成說明寫出比對與執行結果

**強度：MUST**

重跑完成說明必須寫出：比對的每個句型或參數、step 與 Driver 的位置與判定；範疇結果的來源（沿用上次結果的執行代號，或這次執行並存回的執行代號）；範疇內通過與失敗的數量；失敗的 Example 中上次就失敗（開發中）者的位置；單獨重跑後通過的偶發 Example；並寫明未修改任何 step、Driver 與產品程式。不得只寫「rerun 完成」。

### Good Example

這個範例寫出比對結果、這次執行的代號與數量，標出上次就失敗的 Example，並寫明沒有修改程式。

```text
rerun 完成：specs/truth/features/frontend/房間聊天.feature（句型「系統處於 {前置狀態}」只改說明）
比對：shared/系統狀態.js 與 drivers/shared/系統狀態.js → 不用改
結果來源：這次執行 20261120T081500000000Z（任務指令組，已存回）
範疇：18 個 Example，通過 17、失敗 1；失敗的 specs/truth/features/frontend/房間聊天.feature:198 上次就失敗（開發中）；回歸 0
修改：無（只有 verify_result.py 寫入結果檔）
```

### Bad Example

這個範例只寫完成，implement 與使用者看不出比對了哪些 step、結果是沿用還是重新執行，也不知道仍有一個 Example 失敗。

```text
rerun 完成，regressions 0
```
