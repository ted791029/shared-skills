# 用語表

## 端點

| 介面前綴 | 資料夾 | 測試名稱與工具 | 樣板資料夾 | 可用起點 |
|---|---|---|---|---|
| UI | `frontend` | 前端測試：Playwright 為甲、乙各開一個瀏覽器情境操作畫面，後端與 MySQL 實際啟動，起點以 API 建立 | `templates/frontend/` | 系統處於 "對戰開始輪到甲"、系統處於 "雙方各猜兩次" |
| API | `backend` | API 測試：pytest＋httpx（ASGITransport）對真實 MySQL 測試資料庫 | `templates/backend/` | 系統處於 "對戰開始輪到甲"、系統處於 "雙方各猜兩次" |
| DB | `database` | 資料表測試：pytest 以 pymysql 直接讀寫 MySQL 測試資料庫，不經任何 API | `templates/database/` | 系統處於 "對戰開始輪到甲" |

## 模組

| 模組 | 範圍 | feature |
|---|---|---|
| 技能 | 改答案與連猜三次的使用、次數、特效與房間資料表的技能欄位 | frontend/改答案、frontend/連猜三次、frontend/技能特效、backend/改答案、backend/連猜三次、database/連猜三次 |
| 對戰 | 猜測、回合歸屬、勝負與猜測紀錄資料表 | 無（只有 database 猜測紀錄的句型歸屬此模組） |

## 技術說法對照

| 技術說法 | 業務說法 | 使用端點 |
|---|---|---|
| 錯誤碼 four_code_invalid_format | 四碼規則不符（格式） | backend |
| 錯誤碼 four_code_duplicate_digits | 四碼規則不符（重複數字） | backend |
| 錯誤碼 skill_exhausted | 本局次數已用完 | backend |
| aria-invalid="true" | 標示為輸入錯誤 | frontend |
| 主鍵 (room_id, seq) 衝突 | 動作序號已被使用 | database |

## 參數合法值

### `{玩家}`

| 值 | 意義 | 使用端點 |
|---|---|---|
| 甲 | 房主 | frontend、backend、database |
| 乙 | 加入者 | frontend、backend |

### `{技能}`

| 值 | 意義 | 使用端點 |
|---|---|---|
| 改答案 | 換掉自己的祕密答案（使用次數依 002/FR-028） | frontend、backend |
| 連猜三次 | 同一回合逐次連續猜測（規則依 002/FR-012，使用次數依 002/FR-028） | frontend、backend |

## 共用句子

| 句型 | 使用端點 |
|---|---|
| `{玩家} 送出新答案 {四碼}` | frontend、backend |
| `{玩家} 猜 {四碼}` | frontend、backend |
| `雙方的猜測歷史依序為：` | frontend、backend |

## 同名 Rule

| Rule | 使用端點 |
|---|---|
| 送出新答案後，雙方的技能剩餘次數必須同步更新 | frontend、backend |
| 對手不能看到改答案的內容 | frontend、backend |
| 改答案後的猜測必須記進同一回合的猜測歷史 | frontend、backend |
| 不符合四碼規則的新答案必須被拒絕 | frontend、backend |
